# Sound sets

One file per sound group (`<arch>.json` for a Hunter, `boki.json`, `ui.json`), checked by `--sfx-set-check`.
Format and rules: docs/AUDIO.md.
`boki_voices.json` is every species' own voice (`bk_<species>_<mood>`, `KinVoice.cue`).
`garden.json` is the four garden minigames (scripts/home/garden_sfx.gd) and the home chimes (home_chimes.gd).
