# Lace (Hem) r13 tools: Meshy skirt A swapped onto the live body
- `LIVE=<r12 glb> AM=65 pipe13.sh NAME [k=v]` (LIVE must be the pre-swap r12 glb, not the tree file): `rig13.py` (weld, decimate to 24k, fit, skirt-meshy material, mode-A weights, 8 influences) then `refine13.py` closed-loop SkirtSw solve per clip (slit sector + strand zone z<0.45 excluded) then apply.
- `rig13.py` is generated by `make_rig13.py` from `build_head.py` + `../hem_r11/rig11.py`.
- `rtx13.py OUT TASK "style text"`: Meshy retexture, original UV, 2k. `stretch4.py`: stretch3 reading JOINTS_1/WEIGHTS_1. `qr.py` quick CPU views, `render_set.sh` GPU live-audit set (match/close/video/grip).
- Final params: `wd=0.36 cy=-0.005 ww=0.44 cx=-0.035 bk=1.0 kw=0.38 amax=0`, `AM=65`, texture = Meshy retexture T1 (text prompt in `rtx13` call, see gen_log.tsv).
- Retry (r13c): `heelcap13.py IN OUT clips=run,Jump_Run zcap=0.50 reset_sw=1` lowers the back heel kick (Leg keys slerped toward rest only while the foot is behind the hips and above 0.50 m) and clears those clips' SkirtSw keys; then `refine13.py solve` run/Jump_Run with amax=45 and `apply`; finally `python3 tools/art1/glb_add_clips.py b65_T1.glb A45.glb =run,=Jump_Run B45.glb` so the mesh stays byte-identical (a Blender re-export of the whole glb put a 19.1 cm held clip into geo_check).
