# Roster 100 plan (owner direction, Nov 8)

Owner direction: a mix of 2-stage and 3-stage lines, like the classic games, some with branching final forms. A 4th stage is undecided. The game already has four life stages (Hatchling 1, Youngling 4, Grown 8, Elder 16), so if 4-stage lines happen, they would map onto those.

**Branching = the existing affinity paths.** Where a line splits, the path the Boki was raised on (fierce, steadfast, curious, swift) picks the final form. Main would need to add a form swap at the evolution levels and a path check on branching lines.
