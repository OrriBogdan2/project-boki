# Boki 3D models (full access for the art agent, owner 11-10)

The real game files, copied here so you can use them directly. 23 species, 28 models:
- 21 species in the game (copied from origin/main art/kin/<id>/): burrlet cairnback cindle glintmole gloamshell glomwort hivara
  kestrike kindlewren lodestick marchleaf mossgrade nettlynx pebbit puddlet rimeshrew selenfin thrumbird wisplet zapple zephyrak
- 5 fusion forms in the game: <id>_fusion.glb in burrlet, cindle, puddlet, wisplet, zephyrak
- 2 pilot-only, NOT in the game: caecilith, gibbelle (from ext/boki3d-meshy-pilot-rebased)

Each folder: <id>.glb (mesh, rig, animations) + its textures (*_atlas/_eye/_face/_normal.webp).
Open in Blender (File > Import > glTF 2.0) or any glTF viewer; pose/rotate and render any angle you need.
Ready-made renders (6 views each, grey bg) also land tonight in ../3d-refs/.

Rules: the approved 2D design (Bokidex / approved.json) wins for looks where it differs from the 3D; use the 3D for
angles, poses, volume and proportions. Don't edit these files; they are a copy (the game's source is art/kin on main).
