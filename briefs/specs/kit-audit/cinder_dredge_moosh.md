# Audit D: Cinder (ashwick), Dredge (dredge), Moosh Moosh (tender) against the source

Code: main @ 200effce (`scratchpad/main`). Source: briefs/supervive-data (tooltips, physics), hero-ref/{linwick,dredge,mooshmoosh}.md (footage), DECISIONS.md, OWNER_REVIEW_1103.md, EXT_TO_MAIN / INBOX / INBOX_S2 / MAIN_TO_EXT owner answers.
Sources confirmed in kit_comparison.md "Mapping": ashwick = **Felix**, dredge = **Kingpin**, tender = **Elluna** (all "Certain").

Paths below are relative to the main checkout. `K` = scripts/arch/kits/, `A` = content/archetypes/, `DF` = content/dash_flow/.
Conversions: 1 uu = 1 cm. Footage scale is 1 bh ≈ 1.8 m (the convention linwick.md and mooshmoosh.md use; dredge.md uses px and bh only).
Dash numbers include the global dash feel (content/rules/dash_feel.json default: dist x0.85, time x1.15, applied in `ArchKit.travel`, K/../arch_kit.gd:468-471).
Run speeds already come from the game data (content/rules/hunter_move.json: ashwick 4.65, dredge 4.65, tender 4.55 m/s = 465/465/455 uu/s), so they are left out.
Damage values are scaled to our HP (heavy 193, medium 145), so this audit compares damage ratios within a kit, not raw values.

Cross-cutting items that touch all three heroes are at the end.
