# Lace native bow clips: before / after

Rendered on a real GPU (jobq, rp1): `--clip-shots --warden=archer --states --match`.

- `lace_before.mp4` / `lace_after.mp4`: the match camera.
- `lace_side_before.mp4` / `lace_side_after.mp4`: side view, so the draw and release read.

Before: every bow move plays Meshy's one Attack clip. After: each kit move plays its own clip
(tap, draw, over-draw, loose, super, heavy wind and release, Spirit Walk, R).
