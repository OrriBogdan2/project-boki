# Training Area signature drills

The last step of the first-visit kit drill (`KitDrill`, extended; no new screen). After the five slot steps, each Hunter gets one line on its **tech**: the one thing that separates good play from basic play. The line shows live key caps (`{fire}`, `{secondary}`, `{signature}`, `{dash}` follow the player's bindings). The step is done by the kit's own event, `CombatBus.tech(hunter, id)`, emitted at the moment the tech happens, never by a timer. Skip drill ends it as before.

Data: `content/rules/signature_drills.json` (line, dummy rig, source tags). Code: `scripts/match/signature_drill.gd`, `scripts/match/kit_drill.gd`, `scripts/match/arena.gd` (a rigged dummy is left alone). Check: `--kit-drill-check` (runs `tools/signature_drill_check.gd`: for all 12 Hunters the scripted correct input fires the event once, a near miss does not).

Source tags: [owner] owner note, [data] game data (`briefs/supervive-data`), [wiki], [footage] (`briefs/hero-ref/<sheet>.md`). Trust order: owner note > data > wiki > footage; the doc named in brackets holds the full row.
