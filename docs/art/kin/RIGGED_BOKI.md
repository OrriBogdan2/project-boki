# Rigged Boki (Blender model, emoting face, clips)

A species with `art/kin/<id>/<id>.glb` and a row in `BokiRig.FRAME` is drawn from a skinned model instead of
`KinModels`' primitives: Vespyx (`cindle`), Prismander (`puddlet`), Mycroll (`burrlet`), and the NEW design Glintmole
(`glintmole`, roster 50 #11, owner approval pending; not in the game's kin data yet, so only the review tools show it,
from `art/kin/glintmole/stand_in.json`). Also `rimeshrew` (new design, owner approval pending; review tools only, `art/kin/rimeshrew/stand_in.json`). Also `zephyrak` (new design, owner approval pending; review tools only, `art/kin/zephyrak/stand_in.json`). Also `pebbit` (new design, owner approval pending; review tools only, `art/kin/pebbit/stand_in.json`). Everything is generated by
script, so a change to a shape, colour or clip is an edit and a rebuild:

    B=~/tools/blender-4.5.15-linux-x64/blender
    $B -b --factory-startup --python tools/boki/build_boki.py -- --species=<id> --blend=<file.blend>
    $B -b --factory-startup --python tools/boki/build_fusion.py -- --species=<id>
    godot --headless --path . --import

| File | What |
|---|---|
| `tools/boki/boki_sdf.py` | Signed-distance primitives, surface nets, smooth noise |
| `tools/boki/vespyx.py`, `prismander.py`, `mycroll.py`, `glintmole.py`, `rimeshrew.py`, `zephyrak.py`, `gravadillo.py` | The creature: primitives, each naming its bone; work props; palette |
| `tools/boki/vespyx_paint.py` (and the same modules) | The coat, painted off the same fields into a 2k atlas |
| `tools/boki/boki_grown.py`, `boki_tools.py` | Evo's mutations and the tools, placed from each species' anchors |
| `tools/boki/*_fusion.py`, `build_fusion.py`, `scripts/match/boki_fusion.gd` | Fusion parts on the Hunter's torso |
| `tools/boki/face.py` | Eye domes, lids, brows, mouth: one vertex grid, one blend shape per expression |
| `tools/boki/boki_clips.py`, `*_anim.py` | Shared clips, then each species' skeleton and own clips |
| `tools/boki/boki_rig.py`, `build_boki.py` | Armature, weights from the primitives, sampling, .glb export |
| `scripts/match/boki_rig.gd` | Loader and driver (`BokiRig`): clip from metas, face on top, marks and colours |
| `scripts/match/boki_dna.gd` | Inborn proportions, ear and tail shapes, birthmark (`Unique.dress` calls it) |
| `shaders/boki_eye.gdshader`, `boki_marks.gdshader` | Eye with its own iris colour; coat marks fixed to the rest pose |

Clips: idle, walk, run, attack, ability, hop, sleep, eat, pet, chop, mine, carry, tend. Faces (`BokiRig.FACES`): neutral,
happy, sad, sleepy, angry, focus, cheer, bliss, asleep, chew. Set by the metas `kstate`, `happy`, `pulse`, `pose`,
`dazed` (as for `KinPuppet`), plus `kwork`, `kact` and `face`.

Props (axe, pick, berry) are part of the skinned mesh on their own bones, collapsed in every clip that doesn't
use them. Materials: `boki_coat` (atlas, ink), `boki_glow` (the species' glow), `boki_face` (lids, brows, mouth),
`boki_eye`. Face LODs stay off (`FACE_LOD_BIAS`): Godot cuts them from the rest pose, where the lids lie folded.

Checks and review: `--boki-rig-check`; `--boki-rig-shots --shots-dir=<dir>`, then `tools/boki/review_gifs.sh <dir>`.

Eyes: a visible eye about 18-20% of the head's width (the owner asked for smaller eyes in game). The dome is bigger
than what shows: the head covers its rim. Past that the high cameras and `CamRig.char_lean` make it take the face.

Palettes live at the top of each species' coat section (`PLUM`, `SHELL`...); tools held in the tail are Vespyx's `chop`
and `mine` clips, and `boki_clips.chop_mouth` / `mine_mouth` are the mouth versions the others use.

A Boki without legs (Zephyrak) writes all its own clips: the body is a chain bent along a curve sent down it
(`zephyrak_anim.bend`); its FRAME row has `"hip": 0.0` and `"hover": true`, which gives it a soft shadow on the ground.

To add a species: copy `prismander*.py` to its own shapes, coat and clips, add it to `SPECS` (`build_boki.py`),
`MODULES` (`build_fusion.py`), `BokiRig.FRAME` and `BokiFusion.SPECIES`.
