# Architecture

Project Boki is a single Godot 4.6.2 project written in GDScript (standard build, not .NET). Almost
everything is built in code: there's one scene (`scenes/main.tscn`), characters and props are built
from meshes by script, sounds and music are generated by Python tools, and game content is JSON.

## The big pieces

```
scenes/main.tscn -> scripts/main.gd (Main)       one screen at a time: title, prologue, hatch, home,
                                                  match, results, lobby; also every --check hook
autoloads (project.godot)                        Data, Save, Sfx, Settings, Bridge, Game, Net,
                                                  Social, Overlay, Shot, CombatBus
content/*.json  --loaders-->  runtime data        Content, KinLib (grammar), Arch, Gear, World
```

- **Main** (`scripts/main.gd`) holds whichever screen is showing and swaps them through
  `show_screen()`. It also parses command-line flags: the `--*-check` hooks, demos and screenshot
  tooling all start here (see [Checks](Checks.md)).
- **Game** (`scripts/core/game.gd`) is the global glue: input actions, `Game.goto()` /
  `Game.start_match()`, shared state.
- **Data** (`scripts/core/data.gd`) holds tuning that isn't JSON yet: weight classes, rarity,
  perks, monsters, crops, tiers. **Save** (`scripts/core/save.gd`) is the player's persistent state as
  one dictionary (`Save.d`) with migrations for old saves. **Settings** belong to the player, not the save.

## A match

`scripts/match/match.gd` (`Match`) runs one expedition (or the Arena, training, tutorial and duel
room, which are the same class with different options).

- **Fixed step.** The simulation steps at 60 Hz (`Match.DT`); visuals interpolate. Headless checks
  call `Match.step()` directly, as fast as they like.
- **World** (`world.gd`) is a tile grid of ground levels, blockers and the abyss. Expedition maps
  are hand-authored layouts (`content/maps/*.json`, read by `World.generate_authored`); the old
  procedural generator remains for tooling. `terrain_mesh.gd`, `ruin_walls.gd`, `flora.gd` and
  `landmarks.gd` draw it.
- **Entities.** `Ent` is the base for everything that moves and takes damage: `Hunter` (players and
  bots, `bot.gd` drives bots), `Kin` (a Boki in a match, with `KinCompanion` for its teammate
  behaviour), `Mob` (monsters), `Boss`, and the Blight (`blight.gd`, run by `BlightDir`).
- **Systems.** `Life` (down, death, deathboxes, beacons), `Exits` (skiffs, hatches, uplinks),
  `Lairs` + `Boss`, `SpawnPlan` (what's live on a fixed map), `DropSquad` (the drop), `Truce`,
  `RaidLook` (weather and light), `SkyTrain`, `Pack` (backpack), `BiomeRun` (regional monsters and hazards).
- **HUD** (`scripts/ui/hud.gd`) is drawn every frame in code; `full_map.gd` is the M map.

## Combat

- **Class kits.** `Arch` (`scripts/arch/arch.gd`) reads `content/archetypes/<id>.json`; `ArchKit`
  runs one hunter's kit (timers, the RMB variant router, sockets, the bonded R) and each class is a
  subclass in `scripts/arch/kits/`. The weight class (`Data.CLASSES`) still sets health, speed, mass
  and dash charges.
- **Abilities as data.** `AbilityDef` + `AbilityRunner` + `Effects` run JSON abilities (gloves,
  weapon utilities, class dodges). `Verbs` and `Fields` are things abilities leave behind (walls,
  zones). Systems talk through `CombatBus` signals instead of calling each other.
- **Feel and juice.** `oomph.gd` (gameplay weight: hitstop, kick), `juice.gd` (how hits look and
  sound), `arch/feel.gd` (the global feel spec).

## Boki (the kin grammar)

Boki are pure data so outside contributors can add species without shipping code
(`docs/KIN_GRAMMAR.md`). `KinGrammar` loads and validates every file under `content/*_v2`
(`--grammar-check`); `KinParts` is the fixed vocabulary of deliveries, effects, modifiers and
triggers; `KinLib` builds species from checked files; `KinExec` runs any ability spec; `KinRules`
holds the core runtime rules (caps, diminishing returns, slot locks); `KinMerge` runs the bond
ultimate. Nothing named in a file is ever loaded or called.

Raising, identity and economy live in `scripts/core/`: `Care` (needs, bonds, IVs, breeding), `Evo`
(evolution), `Unique` (inborn rolls), `Mutations`, `Shiny`, `KinBox` (the Burrow), `Incubator`,
`Work` (farm jobs), `Econ` (loot and keeping), `Ransom` (lost Boki).

## Home

`scripts/home/home.gd` (`Home`) is the farm screen; helpers split out by area as `RefCounted`
modules it owns: `HomeBuild` + `HomeLayout` (build mode and the saved layout), `HomeWork` (Boki at
work), `HomeGather` (chopping and mining), `HomeEcon` (armory, feeders, graves, shrine),
`HomeIncubator`, plus `interior.gd` (inside buildings).

## Online

Each player's game owns its own hunter and Boki; the host's game owns monsters, bots, loot and wild
Boki. Owners send compact snapshots, and hits on something you don't own go to its owner. On desktop
the messages go through a relay server (the same game run headless with `--relay`); a separate
launcher project handles Discord login and updates. See [Networking](Networking.md).
`docs/ARCHITECTURE_PLAN.md` (on the `design` branch) is the plan for moving to a server-authoritative model; none of it is built yet.

## Art and audio

- Hunters, Boki, monsters, bosses and props are sculpted in code: `models.gd`, `kin_models.gd`,
  `hero_kit.gd`, `hero_gear.gd`, `hero_hair.gd`, `mob_models.gd`, `boss_models.gd`,
  `props_sculpt.gd`, with procedural animation in `hunter_anim.gd` and `kin_puppet.gd`. Some world
  props come from CC0 KayKit packs (`assets.gd`, `art/vendor/`).
- Sound effects (`tools/gen_sfx.py`, `tools/sfx_combat.py`), ambience and music (`tools/compose.py`)
  are generated into `audio/`. `Sfx` plays them; `MusicDir` layers the expedition score.
- Shaders live in `shaders/` (toon, outline, telegraph, rings, clouds, glow, map paint).

## Repository layout

```
content/     game data (JSON): archetypes, classes, kin, kin_v2, abilities, abilities_v2, merges_v2,
             evolution_v2, mutations, gloves, weapons, maps, biomes, combos, rules
scripts/     the game (see Code map)
scenes/      main.tscn
shaders/     .gdshader files
art/, audio/, fonts/, translations/
tools/       check scripts (*_check.gd), generators (gen_*.py, compose.py, make_skyreach.py), build helpers
tests/       galleries and sandboxes (kin, hunters, mobs, props, combat sandbox), net probes, save fixtures
launcher/    the separate launcher project
deploy/      relay server setup
docs/        design docs and this wiki
```
